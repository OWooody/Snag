# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## In short

- Be welcoming and respectful, whatever someone's background or experience.
- Give and accept constructive feedback gracefully, and focus on what is best for the project.
- Harassment, insults, personal or political attacks, and publishing others' private information are not acceptable.

## Scope

This applies in all project spaces (issues, pull requests, discussions) and when representing the project elsewhere.

## Enforcement

Report unacceptable behavior privately to the maintainer, [@OWooody](https://github.com/OWooody), through a direct message or the repository's private vulnerability reporting form. All reports are reviewed promptly and kept confidential. Maintainers may remove comments, commits or contributions that break this code, and may ban contributors who repeatedly do so, following the Contributor Covenant's enforcement guidelines.
